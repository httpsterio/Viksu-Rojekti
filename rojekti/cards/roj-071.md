## What

Two improvements to the epic view:

1. **Hide empty epic groups when filtering** — when any filter is active, epic groups with 0 matching cards are hidden entirely. When no filter is active, all epics show including empty ones.

2. **Sort cards within each epic by status order** — cards are ordered by their status's position in the status list from settings, so the first status appears first.

## How

**Hide empty groups** (`EpicView.vue`) — a `visibleEpics` computed filters `config.epics` by whether the epic has cards when a filter is active. A separate `isFiltering` computed checks all four filter fields (epic, tag, priority, search). Uses `v-for` over `visibleEpics` instead of `config.epics` directly — avoids the `v-if` + `v-for` on the same element lint error.

**Status ordering** (`useBoard.ts`, `cardsByEpic` computed) — after grouping, all groups (including unassigned) are sorted by the index of `card.status` in `config.statuses`. The status order matches the order in settings. Within the same status, cards keep their natural array order (no secondary sort). Cards with a stale/deleted status get `indexOf` returning `-1`, which sorts them to the front — acceptable edge case.
