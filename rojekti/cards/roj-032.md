Priorities are stored as 1-based integers on cards (priority: 1 = highest). The config holds an ordered array of Priority { name, color } objects — position 1 is most urgent, last position is least.

Names are display-only and can be changed freely without touching card files. No rename logic needed.

The settings UI disables reordering since position is the identity.
