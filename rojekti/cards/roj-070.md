## Why

The app currently opens at a default size every launch. Restoring the previous window size and position makes it feel native and removes the friction of resizing on every open.

## What

Save window size and position to `rojekti.state.yaml` when the app closes. On next launch, restore them before showing the window. If the saved position would place the window off-screen (e.g. monitor setup changed), skip restoring position but still restore size.

Crash case is acceptable — state is only written on clean close, so a crash leaves the previous saved state in place.

## How

**`models.rs`** — add four fields to `BoardState`:

```rust
#[serde(default)]
pub window_width: u32,
#[serde(default)]
pub window_height: u32,
#[serde(default)]
pub window_x: i32,
#[serde(default)]
pub window_y: i32,
```

`i32` for position to handle negative coordinates on multi-monitor setups. `#[serde(default)]` handles existing state files without these fields — zeroes are treated as "no saved state".

**`lib.rs` setup()** — before showing the window, read state and apply size/position:

```rust
let state_path = project_dir.join("rojekti").join("rojekti.state.yaml");
let board_state = storage::read_board_state(&state_path);

if let Some(window) = app.get_webview_window("main") {
    if board_state.window_width > 0 && board_state.window_height > 0 {
        let _ = window.set_size(tauri::Size::Physical(
            tauri::PhysicalSize::new(board_state.window_width, board_state.window_height)
        ));
    }
    if board_state.window_x != 0 || board_state.window_y != 0 {
        // TODO: clamp to visible monitor bounds before applying
        let _ = window.set_position(tauri::Position::Physical(
            tauri::PhysicalPosition::new(board_state.window_x, board_state.window_y)
        ));
    }
    let _ = window.show();
}
```

**`lib.rs` setup()** — register a `CloseRequested` handler to save on exit:

```rust
window.on_window_event(move |event| {
    if let tauri::WindowEvent::CloseRequested { .. } = event {
        let size = window.inner_size().unwrap_or_default();
        let pos = window.outer_position().unwrap_or_default();
        let mut board_state = storage::read_board_state(&state_path_clone);
        board_state.window_width = size.width;
        board_state.window_height = size.height;
        board_state.window_x = pos.x;
        board_state.window_y = pos.y;
        let _ = storage::write_board_state(&state_path_clone, &board_state);
    }
});
```

No new Tauri commands needed. No frontend changes. Pure Rust, all in `lib.rs` and `models.rs`.

The window is set to `visible: false` in `tauri.conf.json` and shown manually after size/position are applied — this prevents a visible jump where the window appears at the default size before being resized. Size and position are restored in the correct order before `window.show()`.

The `CloseRequested` handler reads the current state file before writing, so it merges the window fields into whatever the frontend last saved (theme, filters, etc.) rather than overwriting the whole file.

First launch (no state file or all-zero fields) falls through to Tauri's defaults: 1200×800, centered.

## Off-screen guard

Uses `window.available_monitors()` to verify the saved position falls within at least one monitor's bounds before calling `set_position`. If no monitor contains the position, position restore is skipped and the OS places the window on the primary monitor. Size is always restored regardless.

Verified: closing on a second monitor, disconnecting it, then relaunching correctly places the window on the primary monitor.
