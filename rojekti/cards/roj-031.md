## Overview

Store ephemeral user preferences in a separate state file, distinct from `rojekti.config.yaml`. Config is project-level and worth version-controlling. State is local and disposable — if deleted, the app regenerates it with defaults on next launch with no data loss.

## File

`rojekti/rojekti.state.yaml` — adjacent to the config file.

## Contents

```yaml
theme: dark
collapsedStatuses:
  - DONE
  - ARCHIVE
hiddenStatuses: []
activeFilters:
  epic: null
  tag: null
  priority: null
  search: ""
language: en
audioVolume: 0.5
customCursorsEnabled: false
```

`hiddenStatuses` mirrors what's in the config (roj-024) — included here so the "Show hidden" toggle state can be persisted per-session if needed, but the source of truth for which statuses are hidden lives in config.

## Behaviour

- Loaded on startup before the board renders
- Written on every relevant change (theme toggle, lane collapse, filter change, etc.)
- If the file is missing or fails to parse, silently fall back to defaults — never block startup
- Not version-controlled — add `rojekti.state.yaml` to `.gitignore`
