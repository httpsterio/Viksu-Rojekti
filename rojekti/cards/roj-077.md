Instead of a search + filter, we'd have one command palette that can be opened by a keyboard shortcut (ctrl+k or ctrl+p?) or typed directly into. When it's just activated, it'd show some help text on how to use it.

it would support opening settings, changing views (board, epic etc), opening a card or creating a new card.

it should also support searching. when searching @ can be used to filter by epic, # to filter by tag.

when searching it should list all the matching items in the dropdown and let the user click or navigate with arrows to the item.

when filtering it should save the filter as the current state and leave the text in the command palette bar.

not sure if tags should be AND/OR
