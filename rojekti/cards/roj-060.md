## GUI path (`commands.rs`)

Already safe. `create_card` uses a loop that generates a candidate ID, checks whether a file with that name exists in both `cards/` and `deleted/`, and keeps incrementing until it finds a clear slot. Manually dropping a file into the folder with a colliding ID will not cause an overwrite — the next card creation skips over it.

## CLI path (`cli.rs`)

**Bug confirmed.** The CLI `Create` command generates the candidate ID once and uses it without any existence check. If a file with that ID already exists on disk, it will be silently overwritten. Data loss.

## Fix needed

Apply the same loop + existence check from `commands.rs` to the CLI `Create` handler in `cli.rs`.
