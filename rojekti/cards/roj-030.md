## Overview

Add a checklist field to cards — stored in YAML frontmatter, separate from the body/description. Checklists are optional. Cards without one simply omit the field.

## Data model

New struct in `src-tauri/src/models.rs`:

```rust
#[derive(Debug, Serialize, Deserialize, Clone)]
pub struct ChecklistItem {
    pub id: String,
    pub text: String,
    pub done: bool,
}
```

Add to the `Card` struct:

```rust
#[serde(default, skip_serializing_if = "Vec::is_empty")]
pub checklist: Vec<ChecklistItem>,
```

Uses the same pattern as `tags` — omitted from YAML when empty, deserialized as an empty Vec when absent.

## Card file format

```yaml
checklist:
  - id: "abc123"
    text: Write unit tests
    done: false
  - id: "def456"
    text: Update docs
    done: true
```

IDs are required to avoid key collisions in Vue when two items share the same text. Generate with a simple UUID or nanoid on creation.

## CardModal.vue

New **Checklist** section at the bottom of the left (metadata) column, below all other metadata fields. Visible in both view and edit mode.

**Layout:**

```
Checklist  2/5
──────────────────────────────
☑  Write unit tests           ×
☐  Update documentation       ×
──────────────────────────────
Add an item...
```

- Each row: `Checkbox` (PrimeVue) + item text + icon-only `Button` (`pi pi-times`, text severity) for removal
- Bottom: `InputText` with placeholder "Add an item..." — pressing Enter adds the item (trimmed, ignore empty/whitespace), clears the field
- Checkbox toggles and add/remove all update `localCard` only — nothing persists until the Save button is clicked
- `Checkbox` is a new import; `InputText` and `Button` are already imported

## Card.vue (board surface)

When `card.checklist.length > 0`, show a progress indicator in the card footer:

- `<i class="pi pi-check-square"></i> 2/5`
- Muted color by default
- Turns green (or theme success color) when all items are done (e.g. 5/5)
- Hidden entirely when checklist is empty

## TypeScript types

Add `ChecklistItem` to `src/types.ts` (or wherever `Card` is typed) and add `checklist: ChecklistItem[]` to the `Card` type.
