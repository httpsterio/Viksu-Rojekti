# Task: Silent Background Refresh for Watcher-Triggered Reloads

## Problem

`loadBoard()` in `useBoard.ts` always sets `isLoading = true`, which renders a full-screen `ProgressSpinner` overlay that completely hides the board:

```vue
<div v-if="isLoading" class="loading-overlay">
  <ProgressSpinner />
</div>
```

```css
.loading-overlay {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background: var(--bg-primary);
  z-index: 1000;
}
```

When the file watcher detects an external change and calls `loadBoard()`, this causes a jarring full-screen flash — the board disappears and reappears. The initial load and explicit user actions (init, settings save) should keep the spinner. The watcher-triggered reload should not.

## Fix

Add a `silent` boolean parameter to `loadBoard`. When `true`, skip setting `isLoading` and don't show the spinner — just swap the data in the background.

## Files to Change

### `src/composables/useBoard.ts`

Update `loadBoard` signature:

```ts
const loadBoard = async (silent = false) => {
  const generation = ++loadGeneration
  if (!silent) isLoading.value = true
  try {
    const newConfig = await invoke<BoardConfig>("get_board_config")
    const result = await invoke<AllCardsResult>("get_all_cards")
    if (generation === loadGeneration) {
      config.value = newConfig
      cards.value = result.cards
      needsInit.value = false
      for (const error of result.errors) {
        toast.add({ severity: "warn", summary: "Could not load card", detail: error, life: 6000 })
      }
    }
  } catch (e) {
    if (generation !== loadGeneration) return
    console.error("Failed to load board:", e)
    if (typeof e === "string" && (e.includes("config file") || e.includes("board.yaml"))) {
      needsInit.value = true
    } else {
      toast.add({ severity: "error", summary: "Error", detail: String(e), life: 3000 })
    }
  } finally {
    if (generation === loadGeneration && !silent) isLoading.value = false
  }
}
```

Note: this spec assumes the `AllCardsResult` type from `BROKEN_CARDS_SPEC.md` is implemented first. If that spec hasn't been implemented yet, keep using `invoke<Card[]>('get_all_cards')` and skip the `result.errors` loop.

### `src/App.vue` — use silent reload for watcher events

Current:

```ts
await listen("board-changed", () => {
  loadBoard()
})
```

Change to:

```ts
await listen("board-changed", () => {
  loadBoard(true)
})
```

All other `loadBoard()` calls (initial `onMounted`, `initBoard`, `saveBoardConfig`) remain without the `silent` flag so they keep the spinner.

## Notes

- The `silent` parameter defaults to `false` so all existing call sites work without changes
- Only `App.vue`'s `board-changed` listener needs to pass `true`
- The generation counter (already implemented) still applies in silent mode — stale silent reloads are also discarded
- Do not add any visual indicator for silent refreshes — the board just updates in place
