Switch PrimeVue to unstyled mode and install Tailwind CSS. Create a global passthrough (PT) config in `src/themes/rojekti.ts` that styles all used components (Button, ButtonGroup, InputText, InputGroup, InputGroupAddon, Select, MultiSelect, Dialog, Popover, Toast) with Tailwind utility classes.

This replaces Aura entirely and gives full visual control without specificity fights. Dark mode stays class-based (`.dark-mode`) but uses Tailwind's `dark:` variant. Each future theme is a separate PT file.
