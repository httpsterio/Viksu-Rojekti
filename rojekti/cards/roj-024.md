## Overview

Two separate concerns that share the same goal — keeping the main board clean without losing history.

## 1. Hidden lanes

Any status can be hidden from the board view. Hidden statuses don't appear as lanes but remain valid — cards can still be assigned to them via the card modal, and they still appear as options in filters.

**Config:** `hiddenStatuses: string[]` on `BoardConfig` — a list of status names. Follows the same rename/delete propagation as `doneStatuses` (roj-055).

**Settings UI:** a toggle per status in the status list in Board Settings, separate from the name/order editor and the done multiselect.

**Viewing hidden lanes:** a "Show hidden" toggle in the top bar that temporarily reveals all hidden lanes inline on the board without changing the config. Hidden lanes shown this way are visually distinct (e.g. dimmed header) so it's clear they're normally off.

## 2. Deleted cards

Deleted cards are already soft-deleted — moved to `rojekti/deleted/` rather than permanently removed. Add a dedicated view in Board Settings that lists them.

Each entry shows the card ID, title, status at time of deletion, and created date. Clicking a card opens it in the card modal in a read-only state — editing and saving are disabled. The modal footer shows two actions instead of the normal save button:

- **Restore** — moves the file back to `rojekti/cards/`, closes the modal, reloads the board
- **Delete permanently** — removes the file from disk, no recovery, closes the modal

No bulk actions for now.
