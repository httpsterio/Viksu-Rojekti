## Overview

A board-level feature for hiding statuses from the board view. Hidden statuses don't appear as lanes on the board but remain fully valid — cards can still be assigned to them via the card modal. Hidden statuses still appear in the epic view. This is a board-view-only concern.

Hidden statuses are not filter options — filtering by a hidden status would only surface cards that aren't visible on the board anyway, which is confusing.

## Config

`hiddenStatuses: string[]` on `BoardConfig` — a list of status IDs, consistent with `doneStatuses`. `#[serde(default)]` on the Rust field, non-optional `hiddenStatuses: string[]` in the TypeScript interface. Follows the same deletion cleanup pattern in `saveBoardConfig` — strip IDs no longer present in `newConfig.statuses` before saving.

A separate `hiddenStatusesEnabled: boolean` on `BoardConfig` controls whether the feature is active at all. Defaults to false.

## Settings UI

A MultiSelect in Board Settings using `optionValue="id"` and `optionLabel="name"`, bound to `localConfig.hiddenStatuses`. Same pattern as `doneStatuses` — statuses now have frontend-generated UUIDs from `addStatus()` so new statuses appear in the MultiSelect immediately without needing a save first.

A master on/off toggle in settings to enable/disable the whole feature. When off, the MultiSelect and the topbar button are both hidden.

## Hidden button in topbar

The Hidden button (`pi-eye-slash`) is already in TopBar.vue. When clicked it toggles a `showHiddenOnly` view state (not persisted, resets on reload). In normal mode, hidden lanes are not shown. In `showHiddenOnly` mode, all lanes are shown — including hidden ones. This lets the user see the full board temporarily without changing config.

The button is only shown when `hiddenStatusesEnabled` is true. It should appear active/filled when `showHiddenOnly` is on.
