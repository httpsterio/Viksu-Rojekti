## Overview

A board-level feature for hiding statuses from the board view. Hidden statuses don't appear as lanes on the board but remain fully valid — cards can still be assigned to them via the card modal. Hidden statuses still appear in the epic view. This is a board-view-only concern.

Hidden statuses are not filter options — filtering by a hidden status would only surface cards that aren't visible on the board anyway.

## Implementation

**`models.rs`** — two new fields on `BoardConfig`:
- `hidden_statuses: Vec<String>` — list of status IDs, `#[serde(default)]`
- `hidden_statuses_enabled: bool` — master toggle, `#[serde(default)]` (false)

Both init paths (`commands.rs` and `cli.rs`) explicitly set these to empty/false.

**`types/index.ts`** — `hiddenStatuses: string[]` and `hiddenStatusesEnabled: boolean` added to `BoardConfig`, both non-optional.

**`useBoard.ts`**:
- `showHiddenLanes` ref (module-level, not persisted) — toggled by the topbar button
- `visibleStatuses` computed — returns all statuses when feature is off or `showHiddenLanes` is true, otherwise filters out hidden IDs
- `showHiddenLanes` resets to `false` on every `loadBoard` call so it never persists across saves or watcher reloads
- `hiddenStatuses` cleanup in `saveBoardConfig` — same pattern as `doneStatuses`

**`BoardView.vue`** — iterates `visibleStatuses` instead of `config.statuses`.

**`BoardSettingsModal.vue`** — new section with a `ToggleSwitch` for the master toggle and a `MultiSelect` (same pattern as done statuses) that only renders when the toggle is on.

**`TopBar.vue`** — Hidden button wired to `showHiddenLanes`, only shown when `hiddenStatusesEnabled` is true, appears filled/active when `showHiddenLanes` is on.

## Follow-up: persist showHiddenLanes to state

`showHiddenLanes` resets to `false` on every app launch. The toggle state should survive restarts, since the user's intent (wanting to see hidden lanes) is as persistent as any other board view preference.

Fix:
- Add `show_hidden_lanes: bool` to `BoardState` in `models.rs` (`#[serde(default)]`)
- Include it in `Default for BoardState` as `false`
- Save it in the `saveState` watcher in `useBoard.ts` alongside the other state fields
- Restore it on load in the same `if (!stateLoaded)` block
- Add `last_gui_write` stamping to `save_board_state` in `commands.rs` — without it the watcher treats every state save as an external edit and triggers a full `loadBoard`, which resets `showHiddenLanes` back to `false` on every toggle
- Remove the note on line 30 of this card that says it's not persisted, once done

The reset-on-`loadBoard` behavior (line 32 above) is intentional and unrelated — that resets on config reload, not app restart. That can stay.
