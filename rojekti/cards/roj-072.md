## Overview

Deleted cards are soft-deleted — moved to `rojekti/deleted/` rather than permanently removed. Add a dedicated view in Board Settings that lists them and allows restoring or permanently deleting them.

## UI

A new section in Board Settings listing all cards in `rojekti/deleted/`. Each entry shows the card ID, title, status at time of deletion, and created date. Clicking a card opens it in the card modal in a read-only state — editing and saving are disabled. The modal footer shows two actions instead of the normal save button:

- **Restore** — moves the file back to `rojekti/cards/`, closes the modal, reloads the board
- **Delete permanently** — removes the file from disk, no recovery, closes the modal

No bulk actions for now.

## Backend

Two new Tauri commands:

- `get_deleted_cards` — reads all `.md` files from `rojekti/deleted/` and returns them as `Vec<Card>`
- `restore_card` — moves a card file from `rojekti/deleted/` back to `rojekti/cards/`, rebuilds index
- `delete_card_permanently` — removes the file from `rojekti/deleted/` with no recovery
