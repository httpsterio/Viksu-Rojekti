Filtering by Epics work, filtering by Tags does nothing?

## Root cause

`CardMeta` in `models.rs` had `#[serde(skip_serializing_if = "Vec::is_empty")]` on the `tags` field. Cards with no tags were serialized without a `tags` key entirely, so TypeScript received `undefined` instead of `[]`. The filter in `useBoard.ts` then crashed on `c.tags.includes(...)`.

## Fixes

- Removed `skip_serializing_if` from `tags` in `models.rs` so the field always serializes as `[]` when empty, matching the `Card` TypeScript type.
- Added `?.` optional chain on `c.tags.includes(...)` in `useBoard.ts` as a safety net.
- Added `tags: []` to `roj-042.md`, the one card that was missing the field in YAML.
