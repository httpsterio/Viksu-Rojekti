## Overview

A board-level setting that marks one or more statuses as "done". Cards in a done status are considered finished — no changes to card files, just a config-level classification that other features read from.

## Config

Add `doneStatuses` to `BoardConfig` — a list of status names:

```yaml
doneStatuses:
  - DONE
```

Default on init: the name of the last status in the default list. Empty list is valid — no statuses are considered done.

## UI

A new section in Board Settings, separate from the status order/rename editor. A single MultiSelect showing all current status names. Users pick 0–n. Saved as part of the config on save.

If a status that's in `doneStatuses` is renamed, the rename propagation (roj-059) must also update the name in `doneStatuses`. If a status is deleted, its name is removed from `doneStatuses`.

## Effects

Other features read `doneStatuses` to determine card done-ness:

- **Board view** — lanes can be hidden from view independently of done status (roj-024)
- **Epic view** — done cards collapsed at the bottom of each epic (roj-045)
- Potentially: faded styling on cards in done statuses on the main board
