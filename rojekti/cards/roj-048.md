# One-shot Migration: Epic/Tag IDs to Names

## Context

Before roj-022 can ship, existing card files and config must be migrated from ID-based epic/tag references (e.g. `epic: epic-1773924443930`) to name-based references (e.g. `epic: Board`). This is a one-time data migration for the current live board — it does not belong in the application startup code.

**Run this before deploying roj-022.** Once done, this card is complete and the script can be deleted.

---

## What the Script Does

1. Reads `rojekti/rojekti.config.yaml` and builds an ID → name map for epics and tags
2. Rewrites every card file in `rojekti/cards/` that references an epic or tag by ID, replacing the ID with the name
3. Rewrites the config file with `id` fields removed from epics and tags

---

## Implementation

Write a standalone Rust binary at `src-tauri/src/bin/migrate.rs`. It shares the same YAML parsing logic as the main app but runs independently.

```rust
use std::collections::HashMap;
use std::fs;
use std::path::{Path, PathBuf};
use serde::{Deserialize, Serialize};

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
struct LegacyEpic {
    id: String,
    name: String,
    color: String,
}

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
struct LegacyTag {
    id: String,
    name: String,
    color: String,
}

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
struct LegacyBoardConfig {
    name: String,
    prefix: String,
    next_id: u32,
    statuses: serde_yaml::Value,
    epics: Vec<LegacyEpic>,
    tags: Vec<LegacyTag>,
    priorities: Vec<String>,
}

fn main() {
    let dir = std::env::current_dir().expect("Could not get current directory");
    let config_path = dir.join("rojekti").join("rojekti.config.yaml");

    let content = fs::read_to_string(&config_path).expect("Could not read config");
    let legacy: LegacyBoardConfig = serde_yaml::from_str(&content)
        .expect("Config does not look like old ID-based format — already migrated?");

    let epic_map: HashMap<String, String> = legacy.epics.iter()
        .map(|e| (e.id.clone(), e.name.clone()))
        .collect();
    let tag_map: HashMap<String, String> = legacy.tags.iter()
        .map(|t| (t.id.clone(), t.name.clone()))
        .collect();

    println!("Found {} epics, {} tags", epic_map.len(), tag_map.len());

    let cards_dir = dir.join("rojekti").join("cards");
    let entries = fs::read_dir(&cards_dir).expect("Could not read cards directory");

    let mut migrated = 0;
    for entry in entries.flatten() {
        let path = entry.path();
        if path.extension().map_or(false, |e| e == "md") {
            if migrate_card(&path, &epic_map, &tag_map) {
                println!("  migrated {}", path.file_name().unwrap().to_string_lossy());
                migrated += 1;
            }
        }
    }

    println!("{} cards migrated", migrated);

    // Rewrite config without id fields
    // Use raw serde_yaml::Value to preserve all other fields exactly
    let mut raw: serde_yaml::Value = serde_yaml::from_str(&content).unwrap();
    if let Some(epics) = raw.get_mut("epics") {
        if let Some(seq) = epics.as_sequence_mut() {
            for epic in seq.iter_mut() {
                if let Some(map) = epic.as_mapping_mut() {
                    map.remove("id");
                }
            }
        }
    }
    if let Some(tags) = raw.get_mut("tags") {
        if let Some(seq) = tags.as_sequence_mut() {
            for tag in seq.iter_mut() {
                if let Some(map) = tag.as_mapping_mut() {
                    map.remove("id");
                }
            }
        }
    }
    let new_yaml = serde_yaml::to_string(&raw).expect("Could not serialize config");
    fs::write(&config_path, new_yaml).expect("Could not write config");
    println!("Config rewritten without IDs.");
}

fn migrate_card(path: &Path, epic_map: &HashMap<String, String>, tag_map: &HashMap<String, String>) -> bool {
    let content = fs::read_to_string(path).expect("Could not read card");
    let parts: Vec<&str> = content.splitn(3, "---").collect();
    if parts.len() < 3 { return false; }

    let yaml = parts[1].trim();
    let body = parts[2];

    let mut raw: serde_yaml::Value = match serde_yaml::from_str(yaml) {
        Ok(v) => v,
        Err(_) => return false,
    };

    let mut changed = false;

    if let Some(epic_val) = raw.get_mut("epic") {
        if let Some(epic_id) = epic_val.as_str() {
            if let Some(name) = epic_map.get(epic_id) {
                *epic_val = serde_yaml::Value::String(name.clone());
                changed = true;
            }
        }
    }

    if let Some(tags_val) = raw.get_mut("tags") {
        if let Some(seq) = tags_val.as_sequence_mut() {
            for tag in seq.iter_mut() {
                if let Some(tag_id) = tag.as_str() {
                    if let Some(name) = tag_map.get(tag_id) {
                        *tag = serde_yaml::Value::String(name.clone());
                        changed = true;
                    }
                }
            }
        }
    }

    if changed {
        let new_yaml = serde_yaml::to_string(&raw).expect("Could not serialize card");
        let new_content = format!("---\n{}---\n{}", new_yaml, body);
        // Write via tmp for safety
        let tmp = path.with_extension("md.tmp");
        fs::write(&tmp, &new_content).expect("Could not write tmp");
        fs::rename(&tmp, path).expect("Could not rename tmp to card");
    }

    changed
}
```

Add to `src-tauri/Cargo.toml` under `[[bin]]`:

```toml
[[bin]]
name = "migrate"
path = "src/bin/migrate.rs"
```

## Running It

From `src-tauri/`, with the project root as CWD:

```bash
cargo run --bin migrate
```

## After Running

Verify a few card files look correct (epic/tag values are names, not IDs), then delete `src-tauri/src/bin/migrate.rs` and remove the `[[bin]]` entry from `Cargo.toml`.
