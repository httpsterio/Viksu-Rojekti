Card IDs are currently formatted with {:03} (3-digit zero-padded) in both commands.rs and cli.rs. 

This works fine up to roj-999 but at 1000 cards the padding overflows — roj-1000 sorts lexicographically before roj-002, breaking any sorted list or file browser view. The inline link regex already handles
variable-length IDs so that's not an issue.

## Fix
Change {:03} to {:04} in both places:

- src-tauri/src/commands.rs — create_card
- src-tauri/src/cli.rs — Create command

## Migration

Existing cards keep their 3-digit IDs — no renaming. New cards from 1–9999 will be zero-padded to 4 digits. The mixed format is a cosmetic inconsistency but causes no functional issues since IDs are matched by value, not format.

## Note

If you want full consistency from the start, this should be done before the project accumulates too many cards. At {:04} the limit is 9999 cards before the same issue recurs — {:05} would push that to 99999 which is effectively never for a personal tool.
